# Protokol Uji Pengguna Awal (untuk metrik Efisiensi dan Kegunaan)

Metrik ini BELUM diukur. Gunakan protokol ini lalu isi hasilnya; jangan melaporkan angka sebelum diuji.

**Partisipan:** 5-8 mahasiswa akuntansi / praktisi, tanpa pelatihan sebelumnya.
**Data:** dataset demo yang sama untuk semua partisipan.

## Tugas inti (kriteria berhasil)
1. Muat data dan sebutkan berapa transaksi yang gagal validasi. *(angka benar)*
2. Temukan faktor emisi dan sumbernya untuk satu transaksi tertentu. *(faktor dan sumber benar)*
3. Telusuri satu transaksi emisi besar hingga referensi bukti. *(rantai disebut lengkap)*
4. Sebutkan tiga temuan prioritas Tinggi beserta alasannya. *(sesuai daftar aplikasi)*
5. Unduh laporan kesiapan. *(berkas terunduh)*

Kegunaan = tugas berhasil tanpa bantuan / total percobaan tugas. Target internal >= 80%.

## Efisiensi
Bandingkan waktu tugas 2-3 (menelusuri angka dan menyusun daftar bukti) menggunakan spreadsheet + folder dokumen (pembanding manual) dengan menggunakan TRACE ESG. Catat median waktu kedua kondisi, urutan kondisi diacak antar partisipan.
